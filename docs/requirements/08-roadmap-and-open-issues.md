# 08. ロードマップ・未決事項・決定ログ

## 1. リリース案

### Phase 1: MVP Must

- アカウントなしのローカル利用
- ぬいぐるみ登録・編集
- 300文字投稿
- 写真0〜4枚、リサイズ・圧縮
- 日付、時刻、時間不明、場所
- 日別地図と足あと線
- 「きょう」画面
- 「きょうの日記」画面
- 1000文字の一日のまとめ
- 一日の切り替え時刻設定
- 日記案内時刻設定
- 履歴・過去日編集
- 全データ削除

### Phase 1.1: Should

- PWAホーム画面追加
- バックアップ・復元
- ブラウザ印刷・PDF
- 下書き自動保存または未保存警告
- ストレージ使用量表示
- ぬいぐるみ非表示
- 写真の並び順・代表写真
- ぬいぐるみ名・場所名による簡易検索

### Phase 2以降: Future

- LINEログイン
- クラウド保存・複数端末同期
- Web Push通知
- ローカルデータのクラウド移行
- SNS向け共有画像
- 印刷物注文
- 月別・旅行単位のフォトブック
- 高度な検索とタグ
- 動画
- 実GPSルート記録
- 限定的な共同利用

## 2. 確定した主要判断

| ID | 決定 | 状態 |
|---|---|---|
| DEC-001 | 初期版はスマートフォン向けWebブラウザアプリとする | 確定 |
| DEC-002 | 地図は本人の記録用とし、アプリ内公開・共有機能を設けない | 確定 |
| DEC-003 | ひとこと本文は最大300文字 | 確定 |
| DEC-004 | 1投稿の写真は0〜4枚 | 確定 |
| DEC-005 | 画像は縦横比を維持し、容量を抑えて保存する | 確定 |
| DEC-006 | 保存画像を正方形へ強制トリミングしない | 確定 |
| DEC-007 | 日記案内時刻の初期値は21:00 | 確定 |
| DEC-008 | 初期版ではプッシュ通知を実装せず、案内時刻以降に画面内導線を強調する | 確定 |
| DEC-009 | 「きょうの日記」は俯瞰地図、時系列投稿、一日のまとめの順 | 確定 |
| DEC-010 | 一日のまとめは最大1000文字 | 確定 |
| DEC-011 | 時刻不明投稿は一覧末尾へ投稿日時昇順で表示する | 確定 |
| DEC-012 | 時刻不明投稿は足あと線へ含めない | 確定 |
| DEC-013 | 一日の切り替え時刻の初期値は00:00 | 確定 |
| DEC-014 | 一日の切り替え時刻はユーザーが設定から変更できる | 確定 |
| DEC-015 | 一日の切り替え時刻と日記案内時刻は独立して管理する | 確定 |
| DEC-016 | 初期版の主要保存先はブラウザ内ローカル保存 | 現行方針 |
| DEC-017 | LINEログイン、クラウド同期、プッシュ通知は将来拡張 | 現行方針 |
| DEC-018 | MVP実装はReact・TypeScript・Viteを採用し、IndexedDBをDexie経由で利用する | 確定 |
| DEC-019 | 地図providerは環境変数で切替可能にし、初期ローカル設定はOpenStreetMap標準タイルを使う | 暫定 |
| DEC-020 | 保存画像はWebP品質0.82、長辺2,048px、サムネイル480pxとする | 暫定 |
