# 08. ロードマップ・未決事項・決定ログ

## 1. リリース案

### Phase 1: MVP Must

- アカウントなしのローカル利用
- ぬいぐるみ登録・編集
- 300文字投稿
- 写真0〜4枚、リサイズ・圧縮
- 日付、時刻、時間不明、場所
- 日別地図と足あと線
- 「きょう」画面
- 「きょうの日記」画面
- 1000文字の一日のまとめ
- 一日の切り替え時刻設定
- 日記案内時刻設定
- 履歴・過去日編集
- 全データ削除

### Phase 1.1: Should

- PWAホーム画面追加
- バックアップ・復元
- ブラウザ印刷・PDF
- 下書き自動保存または未保存警告
- ストレージ使用量表示
- ぬいぐるみ非表示
- 写真の並び順・代表写真
- ぬいぐるみ名・場所名による簡易検索

### Phase 2以降: Future

- LINEログイン後のクラウド同期
- クラウド保存・複数端末同期
- Web Push通知
- ローカルデータのクラウド移行
- SNS向け共有画像
- 印刷物注文
- 月別・旅行単位のフォトブック
- 高度な検索とタグ
- 動画
- 実GPSルート記録
- 限定的な共同利用

| DEC-004 | 1投稿の写真は0〜4枚 | 確定 |

| DEC-006 | 保存画像を正方形へ強制トリミングしない | 確定 |
| DEC-007 | 日記案内時刻の初期値は21:00 | 確定 |
| DEC-008 | 初期版ではプッシュ通知を実装せず、案内時刻以降に画面内導線を強調する | 確定 |
| DEC-009 | 「きょうの日記」は俯瞰地図、時系列投稿、一日のまとめの順 | 確定 |
| DEC-010 | 一日のまとめは最大1000文字 | 確定 |
| DEC-011 | 時刻不明投稿は一覧末尾へ投稿日時昇順で表示する | 確定 |
| DEC-012 | 時刻不明投稿は足あと線へ含めない | 確定 |
| DEC-013 | 一日の切り替え時刻の初期値は00:00 | 確定 |
| DEC-014 | 一日の切り替え時刻はユーザーが設定から変更できる | 確定 |
| DEC-015 | 一日の切り替え時刻と日記案内時刻は独立して管理する | 確定 |
| DEC-016 | 初期版の主要保存先はブラウザ内ローカル保存 | 現行方針 |
| DEC-017 | LINEログイン、クラウド同期、プッシュ通知は将来拡張 | 現行方針 |
| DEC-018 | MVP実装はReact・TypeScript・Viteを採用し、IndexedDBをDexie経由で利用する | 確定 |
| DEC-019 | 地図providerは環境変数で切替可能にし、初期ローカル設定はOpenStreetMap標準タイルを使う | 暫定 |

| DEC-021 | 将来のクラウド配置はCloudflare Pages・Workers・D1・非公開R2を利用する | DEC-026により置換 |
| DEC-022 | 認証方式確定まではクラウド保存APIを有効化せず、IndexedDBを正本として維持する | 確定 |
| DEC-023 | LINEログイン向け法務情報を `/privacy` と `/terms` で公開し、取得情報を最小限に明示する | 確定 |
| DEC-024 | 新規登録はLINE認証とサーバー管理のあいことばを併用し、登録済み利用者の再ログインではあいことばを不要とする | 確定 |
| DEC-025 | 製品名を「ぬいログ」から「ぬいと」へ変更する。技術識別子 `nuito` は維持する | 確定 |
| DEC-026 | 初回公開はWorkers Static AssetsでSPAとAPIを同一origin配信し、D1・非公開R2を環境別にbindingする | 確定 |
| DEC-027 | 投稿がない日の地図は、許可済みのブラウザ位置情報を利用する。未許可時はプライバシーを優先し、外部IP位置推定サービスへ自動送信しない | 確定 |
| DEC-028 | 操作を表すアイコンはMaterial UI IconsのSVGコンポーネントへ統一し、基本はRounded、日記は`ImportContacts`を使う。個別パスからimportして不要なアイコンをbundleへ含めない | 確定 |
| DEC-029 | 利用開始後は製品名だけの共通ヘッダーを表示せず、各画面の表示領域を優先する | 確定 |
| DEC-030 | 製品アイコンは提供されたおたくま画像を加工せず公開アセットとして利用し、利用開始画面とブラウザーアイコンで共用する | 確定 |
| DEC-031 | DEC-029を置換し、利用開始後は製品名「ぬいと」を共通ヘッダーに表示する。「きょう」以外では画面名を茶色のH1として表示し、同じ画面名を小見出しとして重複表示しない | 確定 |
