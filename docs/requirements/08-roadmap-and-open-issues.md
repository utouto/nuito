# 08. ロードマップ・未決事項・決定ログ

## 1. リリース案

### Phase 1: MVP Must

- アカウントなしのローカル利用
- ぬいぐるみ登録・編集
- 300文字投稿
- 写真0〜4枚、リサイズ・圧縮
- 日付、時刻、時間不明、場所
- 日別地図と足あと線
- 「きょう」画面
- 「きょうの日記」画面
- 1000文字の一日のまとめ
- 一日の切り替え時刻設定
- 日記案内時刻設定
- 履歴・過去日編集
- 全データ削除

### Phase 1.1: Should

- PWAホーム画面追加
- バックアップ・復元
- ブラウザ印刷・PDF
- 下書き自動保存または未保存警告
- ストレージ使用量表示
- ぬいぐるみ非表示
- 写真の並び順・代表写真
- ぬいぐるみ名・場所名による簡易検索

### Phase 2以降: Future

- LINEログイン後のクラウド同期
- クラウド保存・複数端末同期
- Web Push通知
- ローカルデータのクラウド移行
- SNS向け共有画像
- 印刷物注文
- 月別・旅行単位のフォトブック
- 高度な検索とタグ
- 動画
- 実GPSルート記録
- 限定的な共同利用

- 地図サービス
- ローカルDBライブラリまたは方式
- 画像処理方式と実機上のメモリ対策
- 写真保存形式・圧縮設定
- バックアップのMVP採否
- 日記本文の下書き保存方式
- 対応ブラウザ範囲
- 法務ページの初稿を基に、公開前に運営者名、問い合わせ先、施行日を確定し、専門家の確認を受ける
