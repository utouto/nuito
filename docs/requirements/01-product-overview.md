# 01. プロダクト概要

## 1. プロダクトコンセプト

ぬいログは、ぬいぐるみと一緒に出かけた一日を、写真・ひとこと・場所・時刻で記録し、地図と時系列の日記として振り返る個人向けWebアプリです。

SNSへの公開を主目的とせず、ユーザー本人が自分の思い出を安心して蓄積し、「今日はこの子たちと、こんなふうに過ごした」と後から眺められることを重視します。

## 2. 解決したい課題

- 写真アプリだけでは、どのぬいぐるみと、どこへ、どの順番で出かけたかを振り返りにくい。
- SNS投稿は他者への公開を前提にしやすく、個人的な細かな思い出を残しづらい。
- 紙の日記は魅力的だが、外出中に写真・場所・時刻を一体で記録しにくい。
- ぬいぐるみごとの思い出が、写真フォルダやメモへ分散しやすい。

## 3. 対象ユーザー

- ぬいぐるみと一緒に外出、旅行、食事、イベント参加をする人
- ぬい撮りの写真と短い文章を個人的に記録したい人
- 一日の終わりに、行動の流れと感想を日記として振り返りたい人
- 将来的に、記録を紙のノートやフォトブックとして残したい人

初期リリースでは、1人のユーザーが主に1台のスマートフォンで利用する前提とします。

## 4. 提供形態

| 項目 | 方針 |
|---|---|
| アプリ形態 | スマートフォン向けレスポンシブWebアプリ |
| 対象端末 | iPhone、Androidスマートフォン |
| 対象ブラウザ | Safari、Chrome系ブラウザを中心とする |
| PWA | ホーム画面へ追加できる構成を推奨 |
| 通信 | HTTPS必須 |
| 初期保存方式 | ブラウザ内ローカル保存 |
| 地図 | 背景地図と場所検索はオンライン利用を基本とする |
| PC | 閲覧・編集は可能とするが、スマートフォンを優先して最適化 |

## 5. 主要な利用フロー

1. ユーザーがアカウントなしで利用を開始する。
2. 一緒に出かけるぬいぐるみを登録する。
3. 外出先または後から、写真・ひとこと・ぬいぐるみ・場所・日時を記録する。
4. 「きょう」画面で、その日の投稿と地図上の足あとを確認する。
5. 日記案内時刻以降、目立つ「きょうの日記」ボタンから一日を振り返る。
6. 「きょうの日記」で、俯瞰地図と時系列の投稿を見ながら、1000文字以内のまとめを書く。
7. 過去の記録を日付から閲覧・編集する。
8. 必要に応じて、日記を印刷またはPDF保存する。

## 6. 初期リリースの目標

- 撮影から投稿までをスマートフォンで無理なく完了できる。
- 1日の投稿が地図と時系列で自然にまとまる。
- 深夜型など生活リズムが異なる利用者も、一日の切り替え時刻を調整できる。
- アカウントなしでも試せる。
- 公開や交流を意識せず、個人の日記として使える。
- ローカル保存のリスクを明示し、将来のバックアップ・クラウド化へ拡張できる。

## 7. 初期リリースの非目標

初期リリースでは、以下を目的としません。

- 投稿を不特定多数へ公開するSNS
- フォロー、いいね、コメント、ランキング
- 地図やルートの公開URL発行
- アプリが閉じている状態での21時プッシュ通知
- 常時GPSを使った正確な移動経路の記録
- 動画投稿
- 複数ユーザーの共同編集
- App Store、Google Play向けネイティブアプリ固有機能
- 初期版からの印刷物注文サービス

## 8. 成功の判断軸

初期版では数値目標を固定せず、次の体験が成立するかを重視します。

- 初めてのユーザーが、説明なしでもぬいぐるみを登録し、最初の投稿を作成できる。
- 1日に複数投稿したとき、どこへどの順番で行ったか理解できる。
- 21時以降に「きょうの日記」へ自然に気づける。
- 深夜の投稿が、ユーザーの生活リズムに合う日付へ分類される。
- 過去の日記を見返したとき、写真・ぬいぐるみ・場所・感想の関係が分かる。
