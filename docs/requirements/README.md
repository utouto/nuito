## 1. 文書の目的

本要件定義は、ぬいぐるみと一緒に出かけた思い出を、写真・ひとこと・場所・時刻とともに記録するWebアプリ「ぬいログ」について、プロダクト、画面、データ、非機能、テストの共通基準を定義します。

本書群を次の工程で参照します。

- UI・UX設計
- 技術設計
- データ設計
- 開発見積り
- 実装
- テスト設計
- 受入確認
- AIエージェントによる実装・レビュー

## 3. 優先度

| 優先度 | 定義 |
|---|---|
| Must | 初期リリースに必須。欠けると主要体験が成立しない |
| Should | 初期リリースへの搭載を強く推奨するが、段階導入可能 |
| Future | 将来対応。初期リリースの対象外 |
| 暫定 | 方針は採用するが、数値や技術方式は検証後に確定 |

## 4. 要件の正本と変更管理

- 要件ID付きの記述を正本とします。
- 例示は理解を補助するもので、要件ID付き記述と矛盾する場合は要件IDを優先します。
- 仕様変更では、関連する機能要件、受入基準、トレーサビリティ表を同時に更新します。
- 未決事項は推測で確定せず、`08-roadmap-and-open-issues.md` で管理します。

## 5. MVPの要約

### Must

- アカウントなしのローカル利用
- ぬいぐるみ登録・編集
- 300文字以内のひとこと日記
- 1投稿あたり写真0〜4枚
- 画像の縦横比維持、リサイズ、圧縮保存
- 日付・時刻・場所の記録
- 時刻不明の後から投稿
- 日別地図と足あと線
- 「きょう」画面
- 「きょうの日記」画面
- 1000文字以内の一日のまとめ
- 一日の切り替え時刻設定（初期値00:00）
- 日記案内時刻設定（初期値21:00）
- 過去日の閲覧・編集
- ブラウザ内データ保存

### Should

- PWA対応
- バックアップ・復元
- 印刷・PDF保存
- 下書き保護
- ストレージ使用量表示
- ぬいぐるみの非表示
- 写真の代表画像・並び順変更

### Future

- LINEログイン
- クラウド保存・複数端末同期
- プッシュ通知
- 印刷物注文
- SNS向け共有画像
- 実GPSルート記録
- 他ユーザーとの交流機能
