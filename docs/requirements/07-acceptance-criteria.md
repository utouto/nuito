# 07. 受入基準

以下は主要な受入シナリオです。各シナリオは実装テストと受入確認の基準として使用します。

## AC-001 アカウントなしで開始できる

**対応要件:** FR-001, FR-002, FR-003

```gherkin
Given 初回利用者が利用開始画面を開いている
When 「この端末で始める」を選択する
Then ローカル保存の注意事項を確認できる
And アカウント登録なしで「きょう」画面へ進める
```

## AC-002 ローカルデータが再訪後も残る

**対応要件:** FR-170, FR-171

```gherkin
Given 投稿とぬいぐるみが保存されている
When ブラウザを終了し、同じ端末とブラウザで再度開く
Then 保存済みの投稿とぬいぐるみを閲覧できる
```

## AC-003 法務情報を閲覧できる

**対応要件:** FR-007, FR-008

```gherkin
Given 利用者が利用開始画面または設定画面を開いている
When プライバシーポリシーまたは利用規約を選択する
Then 対応する文書を閲覧できる
And 公開URLから文書を直接表示できる
And アプリへ戻ることができる
```

## AC-004 あいことば付きLINE登録

**対応要件:** FR-004, FR-006, FR-009

```gherkin
Given LINEアカウントがぬいとへ未登録である
When 正しいあいことばを入力しLINE認証に成功する
Then 新規アカウントが登録される
When あいことばが一致しない
Then LINE認証に成功しても新規アカウントは登録されない
Given LINEアカウントが登録済みである
When あいことばを入力せずLINE認証に成功する
Then 既存アカウントでログインできる
```

## AC-005 ぬいぐるみの円形アイコンを調整できる

**対応要件:** FR-012, FR-014, FR-040, FR-049

```gherkin
Given ぬいぐるみの登録または編集画面を開いている
When アイコン画像を選択する
Then 円形に表示される範囲を保存前に確認できる
When ドラッグとピンチ、またはスライダーで横位置、縦位置、拡大率を変更して確定する
Then 一覧の円形アイコンへ同じ調整結果が表示される
And 保存された元画像は円形または正方形へ破壊的に切り抜かれない
```

## AC-006 投稿で一緒にいたぬいぐるみを確認できる

**対応要件:** FR-013, FR-016, FR-017

```gherkin
Given 複数のぬいぐるみを選択した投稿が保存されている
When 投稿を表示する
Then 選択したぬいぐるみの円形アイコンが並んで表示される
And ぬいぐるみの名前を「と」で連結した文字列は表示されない
And アイコン画像が未登録のぬいぐるみには既定アイコンが表示される
```

## AC-007 ぬいぐるみのテーマカラーを設定できる

**対応要件:** FR-010, FR-013, FR-014, FR-016

```gherkin
Given ぬいぐるみの登録または編集画面を開いている
Then テーマカラーの初期値は透明である
When テーマカラーを選択して保存する
Then 一覧と投稿に表示されるそのぬいぐるみのアイコンがテーマカラーの線で囲まれる
When 囲み線を透明にして保存する
Then アイコンの囲み線は透明で表示される
```

## AC-010 投稿本文の上限

**対応要件:** FR-020, FR-021, FR-022

```gherkin
Given 投稿作成画面を開いている
When 300文字を入力する
Then 投稿を保存できる
When 301文字を入力する
Then 文字数超過が表示され、投稿を保存できない
```

## AC-011 写真枚数の上限

**対応要件:** FR-024, FR-025

```gherkin
Given 投稿作成画面を開いている
When 写真を4枚追加する
Then 4枚すべてを表示して保存できる
When 5枚目を追加しようとする
Then 追加できないことが分かる
```

## AC-012 画像の縦横比を維持する

**対応要件:** FR-040〜FR-049

```gherkin
Given 縦長または横長の画像を選択した
When 投稿を保存する
Then 保存画像は元画像の縦横比を維持する
And 一覧で正方形表示されても、詳細画面では切り取られていない画像を確認できる
When 一覧の投稿画像をタップまたはkeyboardで選択する
Then 保存画像が本来の縦横比で拡大表示される
And 閉じるボタン、背景のタップ、またはEscapeキーで一覧へ戻れる
```

## AC-013 時刻不明の投稿を保存できる

**対応要件:** FR-028, FR-103

```gherkin
Given 後から記録する投稿を作成している
When 「時間不明」を選び、論理日付を指定して保存する
Then 指定した論理日付へ投稿される
And 投稿日時を行動時刻として表示しない
```

## AC-020 初期状態の日付範囲

**対応要件:** FR-100, FR-102

```gherkin
Given 一日の切り替え時刻が初期値00:00である
When 2026-09-15 00:00以上、2026-09-16 00:00未満の時刻あり投稿を表示する
Then すべて2026-09-15の論理日付へ分類される
```

## AC-021 一日の切り替え時刻を変更できる

**対応要件:** FR-101〜FR-107

```gherkin
Given 一日の切り替え時刻が04:00に設定されている
When 2026-09-16 02:00の時刻あり投稿を保存する
Then 投稿は2026-09-15の論理日付へ分類される
When 2026-09-16 04:00の時刻あり投稿を保存する
Then 投稿は2026-09-16の論理日付へ分類される
```

## AC-022 切り替え時刻変更時の再分類

**対応要件:** FR-104, FR-105, FR-106

```gherkin
Given 時刻あり投稿と時刻不明投稿が保存されている
When 一日の切り替え時刻を変更する
Then 変更の影響が保存前に説明される
And 時刻あり投稿は新設定で日別分類が再計算される
And 時刻不明投稿は指定済みの論理日付を維持する
```

## AC-030 地図上の足あと線

**対応要件:** FR-070〜FR-077

```gherkin
Given 同じ論理日付に、時刻と場所を持つ投稿が3件ある
When 日別地図を表示する
Then 3地点が行動時刻の昇順で点線により結ばれる
And 線は道路に沿った実移動ルートとして表示されない
```

## AC-031 時刻不明投稿を線から除外する

**対応要件:** FR-074, FR-075

```gherkin
Given 場所付きだが時刻不明の投稿がある
When 日別地図を表示する
Then その投稿のピンは表示される
And その地点は足あと線に含まれない
```

## AC-032 投稿編集後に地図が更新される

**対応要件:** FR-034, FR-035, FR-150〜FR-153

```gherkin
Given 日別地図と時系列一覧が表示されている
When 投稿の行動時刻または場所を変更する
Then 地図のピンと点線が再計算される
And 投稿一覧が再並び替えされる
And 保存済みの一日のまとめ本文は変更されない
```

## AC-040 21時以降に日記導線が強調される

**対応要件:** FR-110〜FR-115

```gherkin
Given 日記案内時刻が21:00である
And 現在時刻が論理日の21:00以降である
When 「きょう」画面を表示する
Then 「きょうの日記を書く」または「見る・編集する」ボタンが目立って表示される
And OSのプッシュ通知は送信されない
```

## AC-041 21時前でも日記を書ける

**対応要件:** FR-097, FR-113

```gherkin
Given 現在時刻が日記案内時刻より前である
When 通常の日記導線を選択する
Then 「きょうの日記」画面を開き、本文を保存できる
```

## AC-042 日記案内時刻と切り替え時刻が独立する

**対応要件:** FR-107, FR-110, FR-111

```gherkin
Given 一日の切り替え時刻が04:00である
And 日記案内時刻が21:00である
When 当日21:00から翌日04:00未満に「きょう」画面を表示する
Then 同じ論理日付の日記ボタンが強調される
```

## AC-050 「きょうの日記」の表示順

**対応要件:** FR-130〜FR-139

```gherkin
Given 時刻あり投稿と時刻不明投稿が混在している
When 「きょうの日記」を表示する
Then 時刻あり投稿が行動日時昇順で先に表示される
And 時刻不明投稿が末尾へ投稿日時昇順で表示される
And 時刻不明投稿には「時間不明」と表示される
```

## AC-051 一日のまとめの上限

**対応要件:** FR-140〜FR-148

```gherkin
Given 「きょうの日記」の一日のまとめ欄を編集している
When 1000文字を入力する
Then 保存できる
When 1001文字を入力する
Then 文字数超過が表示され、保存できない
```

## AC-052 投稿がない日にも日記を書ける

**対応要件:** FR-145

```gherkin
Given 対象日に投稿が1件もない
When 「きょうの日記」を開く
Then 一日のまとめを入力し、保存できる
```

## AC-053 日記作成後に投稿が追加される

**対応要件:** FR-150〜FR-154

```gherkin
Given 一日のまとめ本文が保存されている
When 同じ論理日付へ新しい投稿を追加する
Then 地図と一覧に新しい投稿が反映される
And 保存済みの日記本文は保持される
And 必要に応じて記録更新の案内が表示される
```

## AC-060 地図が公開されない

**対応要件:** FR-080〜FR-084, FR-194

```gherkin
Given ユーザーが地図または日記画面を開いている
Then 地図の公開URL発行機能が存在しない
And 他ユーザー閲覧、フォロー、いいね、コメント機能が存在しない
And 地図のSNS直接共有ボタンが存在しない
```

## AC-070 位置情報を拒否しても投稿できる

**対応要件:** FR-060〜FR-066

```gherkin
Given ユーザーが位置情報権限を拒否した
When 投稿を作成する
Then 場所なしで投稿を保存できる
And 位置情報を必須とするエラーにならない
```

## AC-071 保存失敗時に既存データを守る

**対応要件:** FR-173, FR-174, NFR-050〜NFR-053

```gherkin
Given 既存の投稿が保存されている
And 新しい投稿の保存中に容量不足が発生する
When 保存処理が失敗する
Then 失敗理由と再試行方法が表示される
And 既存の投稿は破損しない
And 入力内容は可能な範囲で保持される
```

## AC-080 過去日を編集できる

**対応要件:** FR-160〜FR-165

```gherkin
Given 過去日に投稿と一日のまとめがある
When カレンダーからその日を選択する
Then 地図、投稿一覧、一日のまとめを閲覧できる
And 投稿と一日のまとめを編集できる
```
