# 07. 受入基準

以下は主要な受入シナリオです。各シナリオは実装テストと受入確認の基準として使用します。

## AC-001 アカウントなしで開始できる

**対応要件:** FR-001, FR-002, FR-003

```gherkin
Given 初回利用者が利用開始画面を開いている
When 「この端末で始める」を選択する
Then ローカル保存の注意事項を確認できる
And アカウント登録なしで「きょう」画面へ進める
```

## AC-002 ローカルデータが再訪後も残る

**対応要件:** FR-170, FR-171

```gherkin
Given 投稿とぬいぐるみが保存されている
When ブラウザを終了し、同じ端末とブラウザで再度開く
Then 保存済みの投稿とぬいぐるみを閲覧できる
```

## AC-003 法務情報を閲覧できる

**対応要件:** FR-007, FR-008

```gherkin
Given 利用者が利用開始画面または設定画面を開いている
When プライバシーポリシーまたは利用規約を選択する
Then 対応する文書を閲覧できる
And 公開URLから文書を直接表示できる
And アプリへ戻ることができる
```

## AC-004 あいことば付きLINE登録

**対応要件:** FR-004, FR-006, FR-009

```gherkin
Given LINEアカウントがぬいとへ未登録である
When 正しいあいことばを入力しLINE認証に成功する
Then 新規アカウントが登録される
When あいことばが一致しない
Then LINE認証に成功しても新規アカウントは登録されない
Given LINEアカウントが登録済みである
When あいことばを入力せずLINE認証に成功する
Then 既存アカウントでログインできる
```

## AC-005 ぬいぐるみの円形アイコンを調整できる

**対応要件:** FR-012, FR-014, FR-040, FR-049

```gherkin
Given ぬいぐるみの登録または編集画面を開いている
When アイコン画像を選択する
Then 円形に表示される範囲を保存前に確認できる
When ドラッグとピンチ、またはスライダーで横位置、縦位置、拡大率を変更して確定する
Then 一覧の円形アイコンへ同じ調整結果が表示される
And 保存された元画像は円形または正方形へ破壊的に切り抜かれない
```

## AC-006 投稿で一緒にいたぬいぐるみを確認できる

**対応要件:** FR-013, FR-016, FR-017

```gherkin

Then 選択したぬいぐるみの円形アイコンが並んで表示される
And ぬいぐるみの名前を「と」で連結した文字列は表示されない
And アイコン画像が未登録のぬいぐるみには名前の先頭文字を使った円形の代替アイコンが表示される
```

When 「テーマカラーを設定しない」を選択して保存する

## AC-014 写真の順序と写真ピンを調整できる

**対応要件:** FR-050〜FR-057, FR-070

```gherkin
Given 場所と複数の写真がある投稿を作成または編集している
Then 写真選択は`AddAPhoto`アイコンを伴う「写真を追加」と表示され、ファイル名は表示されない
And 各写真の右上には`HighlightOff`による削除操作が表示される
And 1枚目の左下には鉛筆アイコンによる「ピンに表示する画像を調整」が表示される
And 利用者向け文言には「写真ピン」が表示されない
When 写真をドラッグ、左右スワイプ、または前後移動ボタンで並び替える
Then 並び順の1枚目が代表写真になる
When 1枚目の写真ピン表示範囲を調整して保存する
Then 地図上の直径64pxで茶色い外枠の円形写真ピンに、指定した位置と拡大率で1枚目の写真が表示される
And 写真ピンのひし形の先端が写真円の中央軸に揃って表示される
And 元画像とサムネイルの縦横比は破壊されない
```

## AC-030 地図上の足あと線

**対応要件:** FR-070〜FR-077

```gherkin
Given 同じ論理日付に、時刻と場所を持つ投稿が3件ある
When 日別地図を表示する
Then 3地点が行動時刻の昇順で緩やかな曲線の点線により結ばれる
And 投稿地点の接続部で線が折れて見えず滑らかに続く
And 線は道路に沿った実移動ルートとして表示されない
And 写真付き投稿のピンは白い外枠と1枚目の写真による円形の写真ピンで表示される
And 写真ピンの写真円とひし形には一体となった影が表示される
And 写真の有無にかかわらず地点円は同じ大きさ、共通の茶色い外枠、同行したぬいぐるみのテーマカラーによる内側の円で表示される
And 写真部分は地点円を隠さない位置に表示され、ひし形の先端は写真円の中央軸に揃う
And 複数のぬいぐるみが同行した投稿のピンは内側で各テーマカラーが中心から均等な扇形として明瞭に表示され、色の境界だけがグラデーションになる
```
