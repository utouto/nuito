# 03. 機能要件

## 1. 利用開始・アカウント

| ID | 優先度 | 要件 |
|---|---|---|
| FR-001 | Must | アカウント登録をせずに「この端末で始める」を選択し、利用を開始できる |
| FR-002 | Must | ローカル利用時のデータ消失リスクを、初回画面および設定画面に表示する |
| FR-003 | Must | ブラウザデータ削除、端末故障、端末紛失時には、バックアップがなければ復元できない可能性があることを説明する |
| FR-004 | Future | LINEログインを利用できる |
| FR-005 | Future | ローカルデータをLINEログイン後のクラウドデータへ移行できる |
| FR-006 | Future | LINEの友だち、トーク、タイムライン等へ自動共有しないことを認証時に明示する |
| FR-007 | Must | プライバシーポリシーを初回画面および設定画面から閲覧でき、公開URLから直接表示できる |
| FR-008 | Must | 利用規約を初回画面および設定画面から閲覧でき、公開URLから直接表示できる |

## 2. ぬいぐるみ管理

| ID | 優先度 | 要件 |
|---|---|---|
| FR-010 | Must | ぬいぐるみを新規登録できる |
| FR-011 | Must | ぬいぐるみの名前を登録できる |
| FR-012 | Must | ぬいぐるみのアイコン画像を登録できる |
| FR-013 | Must | アイコン未登録時には既定アイコンを表示する |
| FR-014 | Must | 登録済みぬいぐるみの名前・アイコンを編集できる |
| FR-015 | Must | 1件の投稿に複数のぬいぐるみを選択できる |
| FR-016 | Must | 投稿上で「○○と△△」のように、一緒にいたぬいぐるみを確認できる |
| FR-017 | Must | ぬいぐるみを選択しない投稿も保存できる |
| FR-018 | Should | 使用しなくなったぬいぐるみを非表示にできる |
| FR-019 | Should | 非表示にした場合も、過去の投稿との関連を維持する |

## 3. ひとこと日記の作成・編集

| ID | 優先度 | 要件 |
|---|---|---|

| FR-021 | Must | 入力中の文字数を表示する |
| FR-022 | Must | 301文字以上の場合は保存できない |
| FR-023 | Must | 本文なしでも、写真または場所のいずれかを含む投稿を保存できる |
| FR-024 | Must | 1投稿につき写真を0〜4枚添付できる |
| FR-025 | Must | 5枚目の写真は追加できない |
| FR-026 | Must | 投稿に行動日を設定できる |
| FR-027 | Must | 投稿に行動時刻を設定できる |
| FR-028 | Must | 投稿の行動時刻を「不明」として保存できる |
| FR-029 | Must | 投稿に場所を設定できる |
| FR-030 | Must | 投稿に複数のぬいぐるみを設定できる |
| FR-031 | Must | 「今の記録」と「後から記録」の両方に対応する |
| FR-032 | Must | 「今の記録」は現在日時と現在の論理日付を初期値とする |
| FR-033 | Must | 「後から記録」では日付・時刻・場所を編集できる |
| FR-034 | Must | 保存後に本文、写真、ぬいぐるみ、場所、日付、時刻を編集できる |
| FR-035 | Must | 編集後、日別分類、地図、足あと線、投稿順を再計算する |
| FR-036 | Must | 投稿を削除できる |
| FR-037 | Must | 削除前に確認画面を表示する |
| FR-038 | Future | 削除済み投稿を復元するごみ箱機能を提供する |

## 4. 画像処理・保存

| ID | 優先度 | 要件 |
|---|---|---|
| FR-040 | Must | 保存画像の縦横比を維持する |
| FR-041 | Must | 保存時に正方形へ切り抜かない |
| FR-042 | Must | 詳細画面では画像本来の縦横比で表示する |
| FR-043 | Must | 保存前に端末側で画像をリサイズする |
| FR-044 | Must | 保存前に画質を大きく損なわない範囲で圧縮する |
| FR-045 | 暫定 | 保存画像の長辺上限を2,048px程度とする |
| FR-046 | Must | 画像の向きを補正し、縦写真が横倒しになる等の不具合を防止する |
| FR-047 | Must | 一覧・地図表示用のサムネイルを生成する |
| FR-048 | Must | 一覧・地図では正方形の表示枠を使用できる |
| FR-049 | Must | 正方形表示は表示上のトリミングとし、保存画像自体を破壊しない |
| FR-050 | Should | 写真の表示順を変更できる |
| FR-051 | Should | 代表写真を選択できる |
| FR-052 | Should | 初期状態では1枚目を代表写真とする |
| FR-053 | Should | 最適化後の画像に不要なEXIF位置情報を引き継がない |
| FR-054 | Must | 初期リリースでは静止画のみを扱う |

## 5. 場所登録

| ID | 優先度 | 要件 |
|---|---|---|
| FR-060 | Must | ユーザー操作により現在地を取得できる |
| FR-061 | Must | 位置情報権限は、場所を利用する操作時にのみ要求する |
| FR-062 | Must | 位置情報権限を拒否しても、場所なしで投稿を保存できる |
| FR-063 | Must | 後から投稿場所を指定・修正できる |
| FR-064 | Must | 施設・住所検索、または地図上のピン指定の少なくとも一方を提供する |
| FR-065 | Should | 現在地、施設検索、地図上のピン指定の3方式に対応する |
| FR-066 | Must | 場所情報は任意項目とする |

## 6. 日別地図

| ID | 優先度 | 要件 |
|---|---|---|
| FR-070 | Must | 指定した論理日付の場所付き投稿を地図上にピン表示する |
| FR-071 | Must | 複数地点がある場合、全地点が見えるよう地図範囲を自動調整する |
| FR-072 | Must | 1地点のみの場合、地点を中心に適切な縮尺で表示する |
| FR-073 | Must | 場所と時刻の両方がある投稿を、行動時刻の昇順に点線で結ぶ |
| FR-074 | Must | 時刻不明の場所付き投稿は、ピンのみ表示する |
| FR-075 | Must | 時刻不明投稿を足あと線の順序計算へ含めない |
| FR-076 | Must | 場所がない投稿は地図へ表示しない |
| FR-077 | Must | 点線は実際の道路・移動経路ではなく、思い出の順番を表す線として扱う |
| FR-078 | Should | 点線は直線的になりすぎない、柔らかい視覚表現とする |
| FR-079 | Should | 地図上のピンを選択すると、対応する投稿の概要を表示する |

## 7. 地図の非公開方針
