# 03. 機能要件

## 1. 利用開始・アカウント

| ID     | 優先度 | 要件                                                                                                                                         |
| ------ | ------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| FR-001 | Must   | アカウント登録をせずに「この端末で始める」を選択し、利用を開始できる                                                                         |
| FR-002 | Must   | ローカル利用時のデータ消失リスクを、初回画面および設定画面に表示する                                                                         |
| FR-003 | Must   | ブラウザデータ削除、端末故障、端末紛失時には、バックアップがなければ復元できない可能性があることを説明する                                   |
| FR-004 | Must   | LINEログインを利用できる                                                                                                                     |
| FR-005 | Future | ローカルデータをLINEログイン後のクラウドデータへ移行できる                                                                                   |
| FR-006 | Must   | LINEの友だち、トーク、タイムライン等へ自動共有しないことを認証時に明示する                                                                   |
| FR-007 | Must   | プライバシーポリシーを初回画面および設定画面から閲覧でき、公開URLから直接表示できる                                                          |
| FR-008 | Must   | 利用規約を初回画面および設定画面から閲覧でき、公開URLから直接表示できる                                                                      |
| FR-009 | Must   | 未登録のLINEアカウントは、サーバー管理のあいことばが一致した場合のみ新規登録できる。登録済みアカウントの再ログインではあいことばを不要とする |

## 2. ぬいぐるみ管理

| ID     | 優先度 | 要件                                                                                                                                                                                                             |
| ------ | ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| FR-010 | Must   | 名前・テーマカラー・アイコンをこの順で指定してぬいぐるみを新規登録できる。名前、テーマカラー、アイコン画像の項目見出しは同じ開始位置へ揃える。テーマカラーは「設定する」「設定しない」のラジオボタンで選択し、初期値は「設定しない」とする。カラーピッカーは「設定する」の選択肢の直下に、その選択時だけ表示して操作できる |
| FR-011 | Must   | ぬいぐるみの名前を登録できる                                                                                                                                                                                     |
| FR-012 | Must   | ぬいぐるみのアイコン画像は投稿写真と共通するMUIの写真追加アイコン付き操作で選択し、その直下でドラッグとピンチまたは同等の操作により円形表示の位置と拡大率をプレビューしながら調整できる。調整用の確定ボタンは設けず、ぬいの保存時に表示中の調整値を保存する。小さい一覧サイズに関する説明文は表示しない |
| FR-013 | Must   | アイコン未登録時には、ぬいぐるみ名の先頭文字を円形の代替アイコンの縦横中央に表示する                                                                                                                             |
| FR-014 | Must   | 登録済みぬいぐるみの名前・アイコン・テーマカラーを編集できる。テーマカラーはアイコンの囲み線へ使用し、「設定しない」の場合は透明とする                                                                           |
| FR-015 | Must   | 投稿作成・編集画面ではぬいぐるみを円形アイコンと名前のバッジで表示し、アイコンを選択するとアイコン上のチェックマークでも選択状態を確認できる。1件の投稿に複数のぬいぐるみを選択できる                            |
| FR-016 | Must   | 投稿上で一緒にいたぬいぐるみを円形アイコンで確認できる。複数体の場合は名前の間に「と」を挟んだ文字列ではなく、アイコンを並べて表示する                                                                           |
| FR-017 | Must   | ぬいぐるみを選択しない投稿も保存できる                                                                                                                                                                           |
| FR-018 | Should | 使用しなくなったぬいぐるみを非表示にでき、非表示にした場合も過去の投稿との関連を維持する                                                                                                                         |
| FR-019 | Must   | 登録済みのぬいぐるみを確認後に削除できる。過去の投稿自体は保持し、削除したぬいぐるみとの関連だけを外す                                                                                                           |

## 4. 画像処理・保存

| ID     | 優先度 | 要件                                                                     |
| ------ | ------ | ------------------------------------------------------------------------ |
| FR-040 | Must   | 保存画像の縦横比を維持する                                               |
| FR-041 | Must   | 保存時に正方形へ切り抜かない                                             |
| FR-042 | Must   | 投稿画像をタップまたは選択すると拡大表示でき、画像本来の縦横比で表示する |
| FR-043 | Must   | 保存前に端末側で画像をリサイズする                                       |
| FR-044 | Must   | 保存前に画質を大きく損なわない範囲で圧縮する                             |
| FR-045 | 暫定   | 保存画像の長辺上限を2,048px程度とする                                    |
| FR-046 | Must   | 画像の向きを補正し、縦写真が横倒しになる等の不具合を防止する             |
| FR-047 | Must   | 一覧・地図表示用に縦横比を維持したサムネイルを生成する                   |
| FR-048 | Must   | 一覧・地図では正方形の表示枠を使用できる                                 |
| FR-049 | Must   | 正方形表示は表示上のトリミングとし、保存画像自体を破壊しない             |
| FR-050 | Must   | 写真をドラッグ、左右スワイプ、または前後移動ボタンで並び替え、表示順を変更できる |
| FR-051 | Must   | 並び順の1枚目を代表写真および写真ピンの画像として扱う                    |
| FR-052 | Must   | 初期状態では追加した1枚目を代表写真とする                                |
| FR-053 | Should | 最適化後の画像に不要なEXIF位置情報を引き継がない                         |
| FR-054 | Must   | 初期リリースでは静止画のみを扱う                                         |
| FR-055 | Must   | 代表写真は画像の縦横比から短辺を円の直径へ合わせ、余白が生じない中央位置を初期範囲とする。円形の写真ピンに表示する位置と拡大率を保存前および編集時に「ピンに表示する画像を調整」から調整できる。調整値は別の確定操作を要求せず投稿保存時に保存し、利用者向け文言には「写真ピン」を使わない |
| FR-056 | Must   | 写真選択はMaterial UIの`AddAPhoto`アイコンを伴う「写真を追加」操作として表示し、選択したファイル名は画面に表示しない |
| FR-057 | Must   | 各写真の削除はMaterial UIの`HighlightOff`アイコンを写真右上に表示し、代表写真の表示範囲調整は鉛筆アイコンを1枚目の左下に表示する |
| FR-058 | Must   | 投稿画面にはMaterial UIのカメラアイコンを伴う「カメラを起動」操作を表示し、対応するスマートフォンでは背面カメラを直接起動して撮影した静止画を追加できる。直接起動に対応しない環境ではブラウザ標準の画像選択へフォールバックする |

## 5. 場所登録

| ID     | 優先度 | 要件                                                                                                                                                                                                                       |
| ------ | ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| FR-060 | Must   | 新規投稿時、位置情報権限が許可済みなら現在地を初期場所とし、場所選択地図を現在地付近へ移動する。未許可の場合もユーザー操作により現在地を取得して地図を移動できる。ピンを初めて配置した際の場所名は「ここで遊んだよ」とする |
| FR-061 | Must   | 位置情報権限が未許可の場合は、場所を利用するユーザー操作時にのみ権限を要求する                                                                                                                                             |
| FR-062 | Must   | 位置情報権限を拒否しても、場所なしで投稿を保存できる                                                                                                                                                                       |
| FR-063 | Must   | 後から投稿場所を指定・修正できる                                                                                                                                                                                           |
| FR-064 | Must   | 地図のタップおよび地図上のピンのドラッグで投稿場所を指定・調整できる。選択中のピンは外部画像アセットに依存せず、スマートフォンを含む対応ブラウザで表示される                                                                 |
| FR-065 | Should | 現在地、施設検索、地図上のピン指定の3方式に対応する。現在地取得時はその付近へ地図を移動し、配置したピンを続けて調整できる                                                                                                  |
| FR-066 | Must   | 場所情報は任意項目とする。「場所を記録する」「場所を記録しない」を選択でき、初期値は「場所を記録する」とする。場所指定の説明、地図、場所名入力は「場所を記録する」の選択中だけ当該選択肢の直下へ表示し、説明と地図の間隔を詰める。場所名のラベルと入力値は通常の太さで表示する |

## 6. 日別地図

| ID     | 優先度 | 要件                                                                                                                                                                                                 |
| ------ | ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| FR-068 | Must   | 「きょう」の投稿ドロワーで場所付き投稿を選択すると、現在の地図縮尺を保ち、ドロワーに隠れた領域を除く表示可能範囲の中心へ投稿地点を移動する                                                       |
| FR-069 | Must   | 「きょう」画面に場所付き投稿がない場合、位置情報権限が許可済みならブラウザが取得した現在地付近を地図の初期中心とする。権限が未許可の場合は外部のIP位置推定サービスへ自動送信せず、既定範囲を表示する |
| FR-070 | Must   | 指定した論理日付の場所付き投稿を地図上に円形のピンで表示する。写真付き投稿は直径64pxで白い外枠の写真ピンに1枚目の写真を表示し、ひし形の先端を写真円の中央軸へ揃え、円とひし形を一体とした影を付け、写真なし投稿と同じ色・大きさの地点円が隠れないよう写真部分を上へずらす。地点円は茶色の外枠を使わず3pxの白い縁取りと影を設け、内側に同行したぬいぐるみのテーマカラーを使う。複数体の場合は円の中心から各色を均等な扇形に分け、色の境界だけを短いグラデーションでつなぐ |
| FR-071 | Must   | 複数地点がある場合、全地点が見えるよう地図範囲を自動調整する                                                                                                                                         |
| FR-072 | Must   | 1地点のみの場合、地点を中心に適切な縮尺で表示する                                                                                                                                                    |
| FR-073 | Must   | 場所と時刻の両方がある投稿を、行動時刻の昇順に緩やかな曲線の点線で結ぶ                                                                                                                               |
| FR-074 | Must   | 時刻不明の場所付き投稿は、ピンのみ表示する                                                                                                                                                           |
| FR-075 | Must   | 時刻不明投稿を足あと線の順序計算へ含めない                                                                                                                                                           |
| FR-076 | Must   | 場所がない投稿は地図へ表示しない                                                                                                                                                                     |
| FR-077 | Must   | 点線は実際の道路・移動経路ではなく、思い出の順番を表す線として扱い、その旨の注意書きは地図の下へ常時表示しない                                                                                       |
| FR-078 | Must   | 点線は前後の地点から接線を共有する曲線で補間し、投稿地点の接続部で折れて見えない滑らかな視覚表現とする                                                                                               |
| FR-079 | Must   | 地図上の写真ピンまたは通常ピンを選択すると、そのピンを最前面で拡大し、ドロワー展開後に隠れる領域を除く表示可能範囲の中心へ投稿地点を移動してから、投稿ドロワーを開いて対応する投稿を表示する                                    |
