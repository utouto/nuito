# Repository Skills

このディレクトリは、AIエージェントが利用する反復可能な作業手順と判断基準を管理します。

| Skill | 用途 |
|---|---|
| `implementation` | 通常の機能実装・バグ修正 |
| `debugging` | 不具合の再現・切り分け・原因調査 |
| `project-bootstrap` | テンプレートからの新規プロジェクト初期化 |
| `testing` | テスト設計・実装・実行 |
| `test-review` | テストコード品質レビュー |
| `code-review` | 総合コードレビュー |
| `coding-standards` | 命名・書式・型・エラー処理などの規約適用 |
| `modularity` | 長大ファイル・関数と責務分割の判断 |
| `database` | DB・スキーマ・migration |
| `api-development` | HTTP API開発 |
| `documentation` | docs・README・参照関係の管理 |
| `development-environment` | ローカル開発環境とツール設定 |
| `dependency-management` | 依存関係とライセンス管理 |
| `ci-cd` | CI/CDとデプロイワークフロー |
| `release-management` | バージョン・リリースノート・公開前後の確認 |
| `observability` | ログ・metrics・trace・alert・health check |
| `security-review` | セキュリティ・プライバシーレビュー |
| `performance-audit` | 性能・スケーラビリティ・コスト監査 |
| `accessibility-review` | UIアクセシビリティレビュー |
| `skill-authoring` | Skillの作成・整理 |
| `ai-feature` | AI機能の設計・実装 |

本プロジェクトで不要なSkillは削除できます。本プロジェクト固有の仕様はSkillへ複製せず、`docs/` を正本にしてください。
